# Cards digitais NES

Coloque aqui os PNGs exclusivos para os cards digitais do NES.

- Template recomendado: 512 x 512 pixels, PNG
- Nome igual ao da ROM sem extensao; por exemplo, `Metroid (USA).png`
- Use `labels/nes/Metroid (USA).png` para a etiqueta do cartucho
- Use `labels/nes/cards/Metroid (USA).png` para a imagem do card
- Se nao existir um card, a Fofita usa automaticamente a etiqueta tradicional

Consulte `labels/cards/README.md` para mais detalhes.
